# skingo
Generic browser bingo game framework, supplied with a bingo file inspired by the Skinwalker show.  

![screenshot](/screenshot.png)

100% javascript and HTML. Works pretty well on both desktop and mobile.  

Hosted here: https://potateaux.com/skingo/  

USE:
Just drop it on a web server. Make sure you have the index.html and the squares.txt file. You can change squares.txt to have anything you want in it-- just make sure you've got at least 24 options!
